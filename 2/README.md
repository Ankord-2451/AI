# Лабораторная работа
## Мини-макс с альфа-бета отсечением

### Цель

Я реализовал обычный алгоритм Minimax и его оптимизированный вариант с альфа-бета отсечением, после чего сравнил количество обработанных узлов и время выполнения.

### Условия

- Язык программирования: Python 3
- Глубина дерева: **7**
- Ширина дерева: **2**
- Игроки: **MAX** и **MIN**
- Значения листьев: целые числа
- Часть листьев специально получает одинаковое значение `5`
- Альфа-бета отсечение реализовано рекурсивно

При глубине 7 и ширине 2 полное дерево содержит:

- 128 листьев;
- 255 узлов всего.

### Описание реализации

Игровое дерево строится рекурсивно функцией `build_tree()`. На глубине `0` создаются листья со случайными целыми значениями от `-10` до `10`.

Для проверки равенства значений часть листьев принудительно получает значение `5`. Это позволяет убедиться, что одинаковые значения листьев обрабатываются корректно и не меняют логику выбора Minimax.

#### Обычный Minimax

Функция `minimax()` рекурсивно обходит всё дерево:

- на уровне MAX выбирается максимальное значение;
- на уровне MIN выбирается минимальное значение;
- каждый посещённый узел учитывается в счётчике `nodes`.

#### Alpha-Beta

Функция `alpha_beta()` использует два параметра:

- `alpha` — лучшее найденное значение для MAX;
- `beta` — лучшее найденное значение для MIN.

Если выполняется условие:

```text
beta <= alpha
```

дальнейшее исследование соответствующей ветви прекращается. Такое прекращение называется альфа-бета отсечением.

### Сравнение

Программа отдельно запускает оба алгоритма и измеряет время через `time.perf_counter()`.

Также подсчитывается количество посещённых узлов. После выполнения проверяется:

```python
assert minimax_result == alpha_beta_result
```

Это подтверждает, что оптимизация не меняет результат работы алгоритма.

Программа дополнительно выводит:

- результат Minimax;
- количество проверенных узлов;
- время обычного Minimax;
- результат Alpha-Beta;
- количество проверенных узлов;
- количество отсечений;
- время Alpha-Beta;
- процент сокращения количества проверенных узлов.


### Вывод

В ходе лабораторной работы я реализовал два варианта алгоритма Minimax: обычный и с альфа-бета отсечением.

Оба алгоритма должны выдавать одинаковое итоговое значение корневой вершины. При этом альфа-бета версия может не исследовать часть ветвей дерева, если их значения уже не могут повлиять на итоговый результат.

Таким образом, альфа-бета отсечение позволяет уменьшить количество проверяемых узлов. На небольшом дереве с глубиной 7 разница во времени может быть небольшой, поэтому основным показателем эффективности является количество отсечённых и не посещённых узлов.
